# Ciencia de Datos — Portafolio de trabajos (UNAM / IIMAS)

Repositorio personal para **subir y organizar todos mis trabajos de Ciencia de Datos**, separados por semestre.  
Incluye tareas, proyectos, notebooks, reportes y material de clases.

---

## 📌 Estructura del repositorio

Los trabajos están organizados por semestre:

- **`5to/`** → Material y entregas del 5° semestre  
- **`6to/`** → Tareas y proyectos del 6° semestre  
- **`7mo/`** → Tareas y proyectos del 7° semestre  

Además:
- **`README.md`** → Este documento (guía del repositorio)
- **`push_commits_one_by_one.sh`** → Script auxiliar para subir commits de forma controlada (útil cuando hay muchos cambios)

> Dentro de cada carpeta encontrarás subcarpetas por **materia**, **tarea** o **proyecto**, según corresponda.

---

## 🧭 Cómo usar este repo

### Navegación rápida
1. Entra a la carpeta del semestre (`5to`, `6to`, `7mo`)
2. Busca la materia/proyecto
3. Dentro normalmente encontrarás:
   - `notebooks/` o archivos `.ipynb`
   - reportes `.pdf` / `.html`
   - scripts `.py` / `.R`
   - datos (si aplica)

### Recomendación de convención (opcional)
Para mantenerlo ordenado, cada entrega puede seguir algo como:

```
NombreMateria/
  Tarea_01/
    notebook.ipynb
    reporte.pdf
    src/
    data/ (si aplica)
```

## 🛠️ Requisitos (depende del proyecto)

Los proyectos pueden variar, pero normalmente uso:
